# Fonts (Line Seed Sans TH)

Place these WOFF2 files in this folder so Next.js can bundle them for production:

- `LINESeedSansTH_W_Th.woff2` (weight 100)
- `LINESeedSansTH_W_Rg.woff2` (weight 400)
- `LINESeedSansTH_W_Bd.woff2` (weight 700)
- `LINESeedSansTH_W_He.woff2` (weight 800)
- `LINESeedSansTH_W_XBd.woff2` (weight 900)

If you previously had fonts in `public/fonts/`, copy them here. They will be served from the app bundle and load correctly in production.
